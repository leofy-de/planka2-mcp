This page is a static catalog. To poke the tools live (call tools/list, dispatch tools/call, inspect responses), use the official MCP Inspector against the Docker image:

    -e PLANKA_URL=https://kanban.example.com \
    -e PLANKA_TOKEN=your-bearer-token \
    ghcr.io/leofy-de/planka2-mcp:latest
