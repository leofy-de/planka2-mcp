## [0.1.0] — initial release

The first published version. Seeded here so release-please has a baseline to
append to.

### Features

- Rust MCP server speaking JSON-RPC 2.0 over stdin/stdout.
- Authentication via either `PLANKA_TOKEN` (bearer) or
  `PLANKA_EMAIL` + `PLANKA_PASSWORD`.
- Ten tools tuned for LLM use:
  - `list_projects`, `list_board_summary`, `find_cards`
  - `get_card`, `get_card_context`
  - `create_card`, `update_card`, `move_card`
  - `add_comment`
  - `delete_card` (destructive — excluded from programmatic calling)
- Description sanitisation: inline images stripped, base64 runs collapsed,
  output capped at 1500 chars.
- `move_card` accepts either `list_id` or `list_name`.
- `PLANKA_DEFAULT_CARD_TYPE` env var (`"project"` default, `"story"`
  accepted).
- Multi-arch Docker image published to GHCR
  (`ghcr.io/leofy-de/planka2-mcp`) for `linux/amd64` and `linux/arm64`.
